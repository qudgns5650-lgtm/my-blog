블로그를 두 군데 운영하면 가장 귀찮은 건 **같은 글을 두 번 옮기는 일**입니다. 서식이 깨지고, 표는 다시 그려야 하고, 코드는 한 줄로 뭉개집니다. 그래서 원칙을 하나 세웠습니다.

> 원본은 하나, 출력은 여러 개, 사람은 판단만 한다.

## 전체 흐름

1. 옵시디언에 메모를 적는다
2. 블로그 글 노트로 다듬는다
   1. `slug`에 영문 주소를 적는다
   2. 다 쓰면 `draft` 체크를 끈다
3. 가져오기 스크립트를 실행한다
4. 네이버용 복사 버튼으로 옮긴다

명령은 하나뿐입니다.

```bash
node scripts/import-obsidian.js
```

## 네이버에 붙여 넣으면 생기는 일

네이버 스마트에디터에 일반 HTML을 그대로 붙여 넣으면 일부 서식이 사라집니다. 직접 실험해 본 결과입니다.

| 항목 | 그대로 붙이기 | 네이버용 서식 |
|---|---|---|
| 소제목 | 유지 | 유지 |
| 코드 블록 | 한 줄로 뭉개짐 | 줄바꿈 유지 |
| 표 | 테두리 사라짐 | 테두리 유지 |
| 하위 목록 | 평평해짐 | 들여쓰기 유지 |

그래서 복사하기 전에 서식을 바꿔 줍니다. 핵심은 **네이버가 지우는 구조를 글자와 인라인 스타일로 바꾸는 것**입니다.

- 코드 블록은 줄마다 줄바꿈을 넣은 문단으로
- 목록은 기호와 들여쓰기를 글자로 직접
  - 하위 목록은 `◦` 기호로
  - 번호는 `2-1.`처럼
- 표는 칸마다 테두리 스타일을 붙여서
